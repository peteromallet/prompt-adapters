# Learnings

Learnings are tracked at three tiers. Pick the one that matches your question:

- **[Program learnings](program/learnings.md)** — cross-project findings that apply beyond any single research thread. Methodology, shared architectural insights, data/eval lessons.
- **Project learnings** — cross-experiment findings within one research thread. See each project page (e.g., [text-gemma3-prefix-kv](projects/text-gemma3-prefix-kv.md) → linked Learnings).
- **Experiment learnings** — single-run findings. See each experiment's `LEARNINGS.md` in its directory.

Findings cascade: experiment → project → program. Experiment-level is authored at write-up time. Project and program levels are rolled up periodically when patterns surface.
