# 2026-04-text-002-gemma3-llm-instructions

**Project:** `text-gemma3-prefix-kv`  |  **Parent:** `2026-04-text-001-gemma3-adapter`  |  **Status:** complete

## Question
Does replacing the rule-based instruction generator with Claude-generated content-only instructions fix the T3 (style carryover) failure observed in experiment 001?

## Hypothesis
Experiment 001 used instructions like `"Compose a brief piece on the theme of act and iii"` — noise generated by naive noun-phrase extraction from the target. The model likely had to use the prefix channel to compensate for uninformative instructions, which polluted the style signal. Cleaner content-only instructions should free the prefix channel to carry style signal alone, moving T3 from FAIL toward WEAK or PASS without degrading T1 or T2.

## Method
Identical to experiment 001 except:
- **Instructions**: regenerated via `claude-haiku-4-5` with a target-only prompt enforcing content focus and forbidding style/voice descriptions. System prompt includes 3 few-shot examples.
- **Data paths**: `data/pairs/{train,val,test}.llm.jsonl` (971 / 94 / 94 pairs, same splits and author-pairing as 001).
- **All other knobs unchanged**: base model `google/gemma-3-4b-pt`, 2000 steps, batch 4, bf16, inject layers 17-32, num_queries 16, num_prefix_tokens 16, lr 1e-4/5e-5, cosine schedule.

## Results

| Test | Verdict | Notes |
| --- | --- | --- |
| T1 reference discrimination | PASS | Jaccard 0.201 at n=20. |
| T2 adapter vs prompting | PASS | 70% win rate, 14W/6L/0T at n=20. This is the first robust positive T2 evidence. |
| T3 style carryover | FAIL | 13/20 own-wins, mean advantage approximately zero. Surface features are not measuring useful style carryover yet. |
| T4 memorization and reference leak | PASS / PASS | No memorization or reference-leak failure. |
| T5 loss curve | SLOW | 15.6% improvement over the run. |

## Learnings

Cleaner LLM-generated instructions changed the T2 result from 001's FAIL to a decisive PASS at n=20, so instruction quality is a first-order variable for this architecture. T3 did not improve under the broader evaluation; it failed at n=20, which means the current surface-feature style metric is a broken decision instrument and should be replaced with an LLM-judge style-match test before experiment 003.
